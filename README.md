# SauceDemo Selenium Automation

## Project Overview
This project automates the basic shopping flow of the SauceDemo demo website using Java and Selenium WebDriver.

## Tools Used
- Java
- Selenium WebDriver
- Eclipse IDE
- Google Chrome

## Test Scenarios Automated
1. Login with valid credentials.
2. Open a product details page.
3. Add a product to the cart.
4. Verify the product in the cart.
5. Enter checkout information.
6. Verify the product on the checkout overview page.
7. Read and verify the order confirmation message.

## Test Website
https://www.saucedemo.com/

## Project Type
Self-practice project for learning Selenium WebDriver automation.
